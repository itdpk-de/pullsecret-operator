# Contributing Guidelines

## Making Changes to the API

If you need to modify the ClusterPullSecret API (add fields, change validation, etc.), follow these steps:

### 1. Modify the API Types

Edit the Go struct in:
```
pkg/apis/pullsecret.itdpk.de/v1/clusterpullsecret_types.go
```

Add or modify fields with appropriate kubebuilder markers for validation and documentation.

### 2. Regenerate Generated Code

Run these commands to update all generated files:

```bash
# Generate DeepCopy methods
make generate

# Generate CRDs
make manifests
```

The `make manifests` command will:
- Generate the CRD from your Go types
- Save it to `pullsecret/templates/pullsecret.itdpk.de_clusterpullsecrets.yaml`
- Copy it to `helm-chart/pullsecret-operator/templates/crd.yaml` with a warning header

### 3. Verify Changes

```bash
# Lint the Helm chart
helm lint helm-chart/pullsecret-operator

# Test template rendering
helm template test helm-chart/pullsecret-operator

# Build the operator
go build -o bin/manager ./operator/main.go
```

### 4. Commit Your Changes

Commit all modified files, including:
- Your API type changes
- Generated DeepCopy methods (`zz_generated.deepcopy.go`)
- Generated CRD files (both in `pullsecret/templates/` and `helm-chart/pullsecret-operator/templates/`)

## Important Notes

### DO NOT manually edit these files:
- `pkg/apis/pullsecret.itdpk.de/v1/zz_generated.deepcopy.go` - Generated by `make generate`
- `pullsecret/templates/pullsecret.itdpk.de_clusterpullsecrets.yaml` - Generated by `make manifests`
- `helm-chart/pullsecret-operator/templates/crd.yaml` - Generated by `make manifests`

These files are automatically generated from the Go API types. Any manual changes will be overwritten.

### DO edit these files:
- `pkg/apis/pullsecret.itdpk.de/v1/clusterpullsecret_types.go` - Source of truth for the API
- `operator/controllers/*.go` - Controller logic
- Documentation files (README.md, etc.)
- Examples

## Kubebuilder Markers

Use these markers in your Go structs to control CRD generation:

```go
// +kubebuilder:validation:Required
// +kubebuilder:validation:MinLength=1
// +kubebuilder:validation:Pattern=`^[a-z0-9]([-a-z0-9]*[a-z0-9])?$`
// +kubebuilder:validation:Enum=value1;value2;value3
// +kubebuilder:default="default-value"
// +optional
```

For more information, see the [Kubebuilder documentation](https://book.kubebuilder.io/reference/markers.html).

## Testing Locally

Before submitting a PR:

1. Ensure all generated files are up-to-date: `make manifests && make generate`
2. Build the operator: `go build -o bin/manager ./operator/main.go`
3. Lint the Helm chart: `helm lint helm-chart/pullsecret-operator`
4. Test the Docker build: `docker build -t pullsecret-operator:test .`
